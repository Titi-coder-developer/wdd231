Titi Nail Studio

WDD 231 Individual Project Site Plan

1. Site Name

Titi Nail Studio

The name "Titi Nail Studio" was chosen because the website represents a personal nail-care and beauty business. The name is simple, easy to remember, and suitable for creating a recognizable nail business brand.

2. Site Purpose

The purpose of Titi Nail Studio is to provide customers with information about nail-care and beauty services.

The website will allow visitors to view available nail services, prices, service descriptions, and different nail designs.

Customers will also be able to book a nail appointment online by providing their contact information, selecting a service, and choosing a preferred date and time.

The website will provide a simple and convenient way for customers to learn about Titi Nail Studio and request an appointment.

3. Scenarios

The following questions represent what potential customers may want to know when visiting the website:

  1. What nail services are available and how much does each service cost?
  2. How can I book an appointment for a manicure, pedicure, or nail design?
  3. What types of nail designs are available?
  4. How long does each nail service take?
  5. Where is Titi Nail Studio located and how can I contact the business?

4. Color Scheme

The website will use a soft, elegant, and feminine color scheme that represents beauty, creativity, and professionalism.

Dark Berry #8B3A62
Soft Pink #F4D7E3
Rose #D89AB5
Light Pink #FFF8FB
Dark Gray #333333
  • #8B3A62: Used for the header, footer, headings, navigation, and important buttons.
  • #F4D7E3: Used for soft backgrounds and supporting sections.
  • #D89AB5: Used for borders, accents, highlights, and secondary buttons.
  • #FFF8FB: Used as the main page background.
  • #333333: Used for paragraphs and general text.

5. Typography

Georgia

Georgia will be used for the website title, main headings, and section headings. It provides an elegant appearance that fits the beauty and nail-care theme.

Arial

Arial will be used for paragraphs, navigation, forms, labels, buttons, and general website content. It is simple and easy to read on both mobile and desktop screens.

6. Wireframe

The home page will have two wireframes: one for a small mobile viewport and another for a larger desktop viewport. The wireframes will show the basic structure and placement of the website content before detailed colors, images, and styling are added.

Important: The final wireframes for this project will be created as black-and-white sketches.

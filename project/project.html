WDD 231 Project Proposal

Project Subject: Nail Studio

Project Description

I plan to create a website for a nail studio. The website will provide information about the nail services offered, such as manicures, pedicures, and ready-made nails. It will also have a gallery where customers can view different nail designs, as well as information about the business and how to contact or book an appointment.

Reason and Purpose

I chose this topic because I am interested in nail technology and would like to have my own nail business in the future. I want to create a website that can help customers learn about the services, see different nail designs, and contact the business easily. This project will also help me practice the web development skills I am learning in WDD 231.
